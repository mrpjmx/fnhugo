## 👋 欢迎来到 fnhugo

这是我用 **飞牛系统(fnOS)** + **Hugo** + **PaperMod 主题** 搭起来的个人站。

### 🎯 这个站做什么

- 记录我在飞牛系统上的折腾过程
- 分享 Hugo 站点搭建经验
- 偶尔发一些随笔

### 🛠️ 技术栈

| 组件 | 版本 |
|---|---|
| 飞牛 fnOS | Debian 12 bookworm |
| Hugo | v0.146.0+ |
| PaperMod | v8.0 (commit d376885) |
| GitHub | mrpjmx/fnhugo |

### 📦 仓库结构

```
fnhugo/
├── content/           # 内容(博客)
│   ├── posts/        # 文章
│   ├── about/        # 关于页
│   └── archives/     # 归档页
├── static/           # 静态资源
├── themes/
│   └── PaperMod/     # PaperMod 子模块
└── hugo.toml         # 站点配置
```
